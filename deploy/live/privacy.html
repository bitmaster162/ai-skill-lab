На публичном /start включена собственная форма заявки; прямые каналы связи остаются доступны.

Что собирает форма

Форма может передавать имя совершеннолетнего заявителя или взрослого, организующего обучение, контакт для связи, выбранную аудиторию, описание цели, язык страницы и путь источника заявки. Сервис также создаёт технический request ID и отметку времени.

Куда отправляется заявка

Браузер отправляет заявку на same-origin /api/lead. Vercel проксирует этот путь в изолированный ingress AI Skill Lab; ingress проверяет Origin и данные, подписывает запрос и передаёт его в настроенный оператором HTTPS webhook. После подтверждённого сохранения сервис может отправить оператору техническое уведомление в Telegram только с request ID, временем заявки, выбранной аудиторией и языком страницы. Имя, контакт, описание цели, программа и путь источника в это уведомление не включаются. Секрет подписи не хранится в публичном сайте.

Оператор и срок хранения

Оператор: Dumanyan Robert. Юрисдикция: Thailand. Privacy-контакт: robert@aiskillab.work. Настроенный срок хранения заявок — 30 дней.

AI-route и OpenRouter

Если AI-route включён, он запускается только после нажатия кнопки пользователем. В /api/route передаются выбранная аудитория, три ответа matcher и текст цели. Перед обращением к модели сервер проверяет ввод на шаблоны секретов и ключей; обнаруженный секрет блокируется до вызова модели. Для AI-подбора сервер может передать эти данные в настроенную бесплатную модель через OpenRouter API. Код AI Skill Lab не записывает текст цели или ответы matcher в собственную таблицу rate-limit.

Защита от злоупотреблений AI-route

Для точного ограничения частоты ingress получает сетевой IP клиента от хостинг-платформы и сразу преобразует его в HMAC-token. Сырой IP не записывается в таблицу AI Skill Lab для route-limit. В этой таблице хранятся только request ID, HMAC-token и техническая отметка времени. Плановый cleanup удаляет rate-limit записи старше 24 часов. Token используется только для ограничения частоты и защиты AI-route, а не для рекламного профилирования.

Прямые каналы

Telegram, email, WhatsApp и LINE остаются альтернативными каналами. После перехода во внешний сервис дальнейшая обработка регулируется его условиями и информацией, которую пользователь решит отправить.

Несовершеннолетние

Мы не просим ребёнка самостоятельно оставлять контактные данные. Для youth-программ заявка и организационная коммуникация идут только через контакт взрослого; форма требует подтверждение взрослого для parent/teen сценариев.

Не отправляйте документы, пароли, API keys, платёжные данные или прямой контакт ребёнка. На публичной форме нет checkout и рекламных пикселей.
