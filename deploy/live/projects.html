01VisionAssist

Визуально-семантический слой для evidence-grounded observations, competing hypotheses, counterevidence, uncertainty и явной human-AI revision.

MEMORY · PUBLIC REPOLOCAL-FIRST / OPEN SOURCE

02ContinuityOS

Durable memory и continuity layer для AI-агентов и людей: canon, frontiers, open loops, checkpoints и handoff context.

01ДоказательствоПубличный репозиторий и PyPI package; core memory работает локально на SQLite, поддерживает CLI, Python API, MCP и импорт AI-history из нескольких провайдеров.

02Граница claimsDemo доказывает bounded persistence через новый процесс, а не поведенческую идентичность модели или production security.

GitHub ↗
AGENT GOVERNANCE · PUBLIC REPODETERMINISTIC REFERENCE

03BitEvo Agent Authority

Публичный reference package семи ворот Agent Authority & Evidence для проверки одного action-capable workflow.

01Доказательствоspec/gates.json, локальный deterministic evaluator, fail-closed validation и regression tests; package source-bound к публичной BitEvo реализации.

02Граница claimsНе выдаёт trust/safety score, не сертифицирует систему, не исполняет внешние действия и не запрашивает credentials.

AI PRODUCT · PUBLIC REPOPUBLIC PRODUCT / EVIDENCE SURFACE

04BitEvo Agent Site

Публичный продукт для authority-first AI-agent engineering, где SOURCE, BUILD, DEPLOYMENT, READBACK и EXTERNAL EFFECT разделены как разные классы доказательств.

01ДоказательствоAstro site с provider-bound build receipts, deterministic release gates, CSP hash allowlist и раздельными Vercel / Cloudflare provider paths.

02Граница claimsProduction promotion отделён от build/readback; публичный repository прямо фиксирует can_trade=false и capital_permission=DENY.

9 / 9 проектов показаноЛокальный фильтр · данные не отправляются
01 · RESEARCH8–13

01Детектив фактов

Тема → 3+ источника → таблица утверждений → короткая презентация «что подтвердилось / что нет».

01ЗадачаОтделить проверяемый факт от красивого ответа.

02AI roleПомогает сформулировать поисковые запросы, сравнить версии и организовать находки.

03Human checkОткрывает источники, отмечает противоречия и объясняет, почему выводу можно доверять.

04ArtifactSource table + claim map + мини-презентация.

02 · CREATE8–13

02Мир и персонаж

Character bible, визуальные правила, storyboard и итоговая мини-история с явным разделением своей идеи и AI-помощи.

01ЗадачаПревратить идею в последовательную систему мира и персонажей.

02AI roleПредлагает варианты, референс-направления и помогает проверять внутреннюю логику.

03Human checkВыбирает художественные решения и может объяснить, что придумал сам и где использовал AI.

04ArtifactCharacter bible + storyboard + finished story.

03 · LOGIC8–13

03Мини-игра

Правила, состояния, простая логика и прототип. Ребёнок показывает, почему система работает именно так.

01ЗадачаСобрать маленькую работающую систему вместо одноразовой генерации.

02AI roleПомогает разложить механику на правила, состояния и тестовые сценарии.

03Human checkПроверяет причинность, чинит сломанные правила и защищает логику проекта.

04ArtifactGame rules + state map + playable prototype.

04 · STUDY14–18

04Research OS

Шаблон исследования: вопрос, источники, тезисы, проверка, итоговый memo и presentation.

01ЗадачаСделать исследование повторяемым процессом, а не случайным набором вкладок.

02AI roleРасширяет поиск, группирует evidence и помогает видеть конфликтующие версии.

03Human checkОценивает качество источников и принимает аргументированный вывод.

04ArtifactResearch template + evidence map + memo + presentation.

05 · BUILD14–18

05AI assistant prototype

Простой ассистент или workflow под реальную задачу: input, rules, output, failure cases и README.

01ЗадачаПревратить задачу в спецификацию, которую можно протестировать.

02AI roleПомогает с декомпозицией, prompt/system rules, glue-code и тестовыми случаями.

03Human checkОпределяет границы, проверяет ошибки и решает, где автоматизация должна остановиться.

04ArtifactPrototype + test cases + README + failure map.

06 · PRODUCT14–18

06Mini-product

Проблема пользователя, прототип, тестовые сценарии, ограничения и короткий demo.

01ЗадачаПроверить продуктовую гипотезу работающим артефактом.

02AI roleПомогает исследовать варианты, собрать интерфейс и ускорить итерации.

03Human checkРежет scope, разговаривает с пользователем и принимает продуктовые решения.

04ArtifactWorking prototype + QA checklist + demo + known limits.

07 · WORKFLOWAdults

07Personal research workflow

Повторяемая система поиска, сравнения источников, synthesis и проверки.

01ЗадачаСократить путь от вопроса до решения без потери source discipline.

02AI roleСобирает варианты, сравнивает evidence и формирует структуру decision brief.

03Human checkПроверяет первоисточники, допущения и владеет финальным решением.

04ArtifactReusable workflow + source map + decision brief template.

08 · AUTOMATIONAdults / business

08Process prototype

Ассистент или automation для одного повторяемого процесса с ownership и fallback.

01ЗадачаАвтоматизировать один процесс так, чтобы оставался понятный владелец и rollback.

02AI roleВыполняет повторяемые трансформации, маршрутизацию и черновую обработку.

03Human checkОпределяет permissions, failure modes, acceptance criteria и fallback.

04ArtifactWorkflow + acceptance tests + handoff + rollback path.

09 · PLAYBOOKAdults / business

09AI operating rules

Шаблоны задач, критерии проверки, data boundaries и инструкции для повторного использования.

01ЗадачаПеревести разрозненные удачные промпты в управляемую операционную систему.

02AI roleПомогает формализовать повторяемые шаблоны, проверки и варианты исполнения.

03Human checkФиксирует права, данные, ответственность и правила эскалации.

04ArtifactPlaybook + task templates + verification rules + governance notes.
