Система итераций.

Это milestone snapshot, а не полный changelog. Exact identity текущего release всегда лежит в /_release.json.

R8 · BASELINE

Proof + parent decision layer

Первая переносимая source authority и честный proof-контур без фальшивых отзывов и обещаний.

R24 · COMMERCIAL

Commercial parity

Цены, пакеты и формулировки сведены в единую коммерческую правду и защищены parity gate.

R31 · RUNTIME

Behavior, not markup

После реального syntax-багa static matcher появились runtime smoke-tests, no-JS fallback и проверяемый Start flow.

R38 · GOVERNANCE

Security + structured data

Hashed CSP, privacy contract, metadata/structured-data integrity и semantic gates стали release-требованиями.

R49 · RELEASE

Deterministic builder

Artifact, manifest и wrapper стали собираться и восстанавливаться byte-for-byte вместо ручной упаковки.

R60 · EXPERIENCE

Site becomes the demo

Proof Lab, Project Studio, Pilot Simulator, Brief Compiler, Challenge и Skill Graph превратили сайт в интерактивное доказательство.

R65 · ATTENTION

Product-scene hero

Hero начал показывать ACTIVE WORKFLOW → DEFINE → BUILD → VERIFY → SHIP вместо абстрактной AI-иллюстрации.

R66 · PROVENANCE

Build process becomes public

История сборки, failures, toolchain и границы ответственности становятся частью самого продукта.

R68 · TRANSFER

Performance becomes a contract

Worst-case first view держится примерно в 14 KB Brotli: HTML + общий CSS + LAB runtime. Бюджет проверяется на каждом релизе.

Failure log

Сильнее всего
система выросла на ошибках.

Полезная ошибка должна менять систему так, чтобы её класс больше не проходил незамеченным.

FAILURE → CONTROL

STATIC JS BROKE

Deployable static matcher содержал syntax error.

→ Добавили syntax gate + behavioral runtime smoke.

FAILURE → CONTROL

METADATA DRIFT

RU/EN и source/static расходились по social/SEO metadata.

→ Добавили deterministic metadata, hreflang и structured-data gates.

FAILURE → CONTROL

WRAPPER CORRUPTED

Один release-wrapper оказался повреждённым.

→ Builder теперь проверяет archive SHA, manifest SHA и byte-exact reconstruction.

FAILURE → CONTROL

SANDBOX DISAPPEARED

Рабочая директория исчезла во время итерации.

→ Exact проект восстановили из Git bundle.

FAILURE → CONTROL

DEPLOYMENT BLOCKED

Vercel quota/provider blockers мешали выпуску.

→ Source, build, deployment и readback остались разными состояниями; blocker не объявлялся PASS.

Что это доказывает
