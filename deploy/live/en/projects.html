Five projects by Robert Dumanyan with public repositories and inspectable scope. These are mentor builds, not student work or client case studies.

VISUAL AI · PUBLIC REPORESEARCH / OFFLINE TESTABLE

01VisionAssist

A visual-semantic cognition layer for evidence-grounded observations, competing hypotheses, counterevidence, uncertainty and explicit human-AI revision.

01EvidenceThe public repository documents a 75-case corpus: 60 market chart cases plus 15 deterministic visual-control cases, with an offline harness, scorer and proof checklist.

02BoundaryThe README makes no calibration, human-AI uplift, natural-scene generality or production-value claim.

MEMORY · PUBLIC REPOLOCAL-FIRST / OPEN SOURCE

02ContinuityOS

Durable memory and continuity for AI agents and humans: canon, frontiers, open loops, checkpoints and handoff context.

01EvidencePublic repository and PyPI package; core memory is local SQLite and supports a CLI, Python API, MCP and multi-provider AI-history import.

02BoundaryThe demo proves bounded persistence across a fresh process, not behavioral model identity or production security.

GitHub ↗
AGENT GOVERNANCE · PUBLIC REPODETERMINISTIC REFERENCE

03BitEvo Agent Authority

A public seven-gate Agent Authority & Evidence reference package for examining one action-capable workflow.

01Evidencespec/gates.json, a local deterministic evaluator, fail-closed validation and regression tests; the package is source-bound to the public BitEvo implementation.

02BoundaryIt does not issue a trust/safety score, certify a system, execute external actions or request credentials.

GitHub ↗
AI PRODUCT · PUBLIC REPOPUBLIC PRODUCT / EVIDENCE SURFACE

04BitEvo Agent Site

A public authority-first AI-agent product where SOURCE, BUILD, DEPLOYMENT, READBACK and EXTERNAL EFFECT are kept as separate evidence classes.

01EvidenceAstro site with provider-bound build receipts, deterministic release gates, a CSP hash allowlist and separate Vercel / Cloudflare provider paths.

02BoundaryProduction promotion is separate from build/readback; the public repository explicitly fixes can_trade=false and capital_permission=DENY.

GitHub ↗
CONTROL STACK · PUBLIC REPOVALIDATION-ONLY

05TRIAXIS

A versioned governance/control stack with deterministic validation assets for policy binding, external witnesses, execution reconciliation and rollback detection.

01EvidenceThe public repository includes executable validation harnesses for signed policy heads, quorum, execution ledger, provider reconciliation and completion witnesses.

02BoundaryThe repository explicitly says it is not a production gateway; validation results do not prove production exactly-once behavior or complete mediation.

01Fact detective

04ArtifactSource table + claim map + mini presentation.

02World & character

Character bible, visual rules, storyboard and a short final story with clear separation between the learner’s idea and AI assistance.

01GoalTurn an idea into a coherent system of world and character rules.

02AI roleExplores alternatives, reference directions and consistency checks.

03Human checkOwns the creative choices and can explain what came from them versus AI assistance.

04ArtifactCharacter bible + storyboard + finished story.

03Mini game

Rules, states, simple logic and a prototype the learner can explain.

01GoalBuild a small working system instead of a one-shot generation.

02AI roleHelps decompose mechanics into rules, states and test scenarios.

03Human checkChecks causality, repairs broken rules and defends the project logic.

04ArtifactGame rules + state map + playable prototype.

A reusable research template: question, sources, claims, verification, memo and presentation.

01GoalMake research a repeatable process instead of a pile of browser tabs.
