SOURCE-BOUND

01Candidate scopeПовторяемый поиск по разрешённой базе знаний, где ответ обязан опираться на конкретные источники.

02AI roleНаходит кандидатов, сравнивает фрагменты, собирает черновой ответ и отмечает неопределённость.

03Human checkpointПроверяет первоисточник, доступ к данным и принимает ответ перед использованием в работе.

04Success signalЗаранее согласованный порог reviewer acceptance и времени на подготовку source-backed ответа.

05Stop conditionИсточники не покрывают вопрос, права доступа неясны или проверка занимает не меньше времени, чем текущий процесс.

06Pilot artifactWorkflow spec + source rules + test set + fallback.

ХОРОШИЙ КАНДИДАТ

Где пилот имеет смысл

✓ повторяемая knowledge-work задача с понятным входом и выходом
✓ документы, research, классификация, черновики или подготовка решений с human review
✓ есть владелец процесса и понятен хороший результат
✓ можно начать с ограниченного пилота без автономного доступа к критичным действиям
СТОП-СИГНАЛЫ

Где сначала нужен другой разбор

× нет владельца процесса или никто не готов проверять результат
× нужно полностью автономное safety-critical решение
× нет права использовать данные или неясны privacy boundaries
× ожидание — одна кнопка вместо процесса, владельца и контроля
HANDOFF

Артефакты, а не AI-театр.

Current-state map · candidate backlog · prototype / automation · test cases · human checkpoints · privacy/data boundaries · owner & fallback · operating notes.

DECISION GATE

Ship · Revise · Stop.

До сборки фиксируем приемлемый результат: качество выхода, обязательный human review, допустимые failure modes, data boundaries, fallback и владельца процесса. После теста решение принимается по этим критериям, а не по эффектности demo.

01

SHIP

Критерии проверки пройдены, owner принимает процесс и понятно, кто контролирует работу дальше.

02

REVISE

Ценность есть, но ограниченные проблемы качества, данных, UX или operating rules требуют ещё одного цикла.

03

STOP

Риск, отсутствие владельца, слабое качество или ограничения данных делают внедрение хуже текущего процесса. Обязательства «внедрить AI» нет.
